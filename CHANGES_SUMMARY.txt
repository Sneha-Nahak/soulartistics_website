HOW TO USE
================================================================================

Adding New Projects:
1. Open: src/config/cloudinaryConfig.js
2. Find desired category (uiuxDesign or branding)
3. Add project object to projects array
4. Update Behance link with your actual URL

Adding New Categories:
1. Open: src/config/cloudinaryConfig.js
2. Add new category object to imageCategories
3. Component automatically creates new tab
4. Projects render in cards

Customizing:
- Project card styling: src/styles/ProjectCard.css
- Page layout: src/styles/UIUXBranding.css
- Tab styling: src/styles/TabNavigator.css
- Data: src/config/cloudinaryConfig.js
